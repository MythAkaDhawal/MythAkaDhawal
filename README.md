### A PDF and a highlighter

My favourite way to read an AI-generated answer is with the original page open beside it. Could I highlight the sentence that supports the claim? **CiteRAG** is my attempt to make that check easier. The prototype breaks a PDF into passages, retrieves a few for the question, and passes them to Gemini. The interesting case is a citation that lands in the right paragraph while the answer quietly says more than the paragraph does. [Explore CiteRAG](https://github.com/MythAkaDhawal/CiteRAG---Citation-Grounded-Document-Q-A-via-RAG)

### A message from “your bank”

Paste a message into **ScamNet.ai** and a browser extension asks a classifier behind a FastAPI endpoint to assess the text. The part I’m working toward is what happens *after* the warning. If my bank and a scammer both write “urgent,” what evidence would actually help me decide whether to act? [Explore ScamNet.ai](https://github.com/MythAkaDhawal/Scamnet-ai)

### A mouse with no buttons

**Gesture-Smart** lets me control my PC with hand gestures. It comes with my favourite interface-design question in these repos. How does the computer tell the difference between a command and me just talking with my hands? [Explore Gesture-Smart](https://github.com/MythAkaDhawal/Gesture-Smart)
